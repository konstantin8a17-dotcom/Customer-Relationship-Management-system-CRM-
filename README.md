# Customer Relationship Management System (Sales CRM)

CRM уеб система за цялостно управление на контакти, компании, търговски фунии (Pipeline), задачи, срещи в календар и подробни отчети за продажби.

---

## 🚀 Как се стартира приложението

### 1. Изисквания
- **Node.js** (версия 18 или по-нова)
- **npm** (инсталиран с Node.js)

### 2. Инсталиране на зависимостите
Отворете терминал в главната директория на проекта и изпълнете:
```bash
npm install
```

### 3. Стартиране в режим на разработка
За да стартирате сървъра:
```bash
npm run dev
# или
npm start
```

След стартиране сървърът ще бъде достъпен на:
```
http://localhost:3000
```
